사용 방법

1대시보드 개요

본 도구는 강사가 공유 드라이브에 올린 강의 교안을, 수강생이 편집·다운로드 없이 목차와 함께 열람하도록 배포하는 관리 도구다. 배포된 강의는 키워드 하나로 주소가 고정된 뷰어 페이지를 통해 열람된다.

교안을 새 슬라이드로 갱신해도 같은 키워드로 재등록하면 기존에 공지한 링크는 유지된 채 내용만 갱신된다. 이 외에 수업 중 실시간 설문, AI를 이용한 시험문제 생성 등의 기능을 제공한다.

2강의 등록 (배포) 절차

  1. 강의 PPT 파일을 구글 드라이브의 강의교안 공유폴더에 업로드한다.
  2. 업로드한 파일을 열어 파일 → Google 슬라이드로 저장을 실행한다. PPT 파일을 그대로 열어둔 화면의 주소는 등록 대상이 아니며, 반드시 이 과정을 거쳐 생성된 구글 슬라이드 파일이어야 한다.
  3. 변환된 구글 슬라이드 편집 화면의 주소창 URL을 복사한다.
  4. 대시보드 우측 상단의 + 새 강의 추가하기 버튼을 선택한다.
  5. 키워드(학생용 뷰어 주소에 고정 사용, 등록 후 변경 불가), 강의 제목, 앞서 복사한 슬라이드 URL을 입력한다. 이미 등록된 키워드는 신규 등록 대상이 아니다(변경은 4번 항목 참고).
  6. 목차 추출 방식을 선택한다 — 제목만 추출 (기본값, 제목 개체가 있는 슬라이드만 목차에 포함) 또는 첫 번째 문자열 사용(모든 슬라이드에서 맨 위 텍스트를 목차 항목으로 사용).
  7. 배포 버튼을 선택하면 등록이 완료되고 목록에 즉시 반영된다.

3뷰어 링크

목록의 뷰어 URL 칸 아이콘으로 링크를 복사하거나 새 창으로 열기할 수 있다(아이콘에 마우스를 올리면 전체 주소가 풍선 도움말로 표시된다).

이 링크(?k=키워드)는 로그인 여부와 무관하게 열람 가능하며, 한 번 게시판 등에 공지한 이후 교안을 갱신해도 주소는 변경되지 않는다.

4배포 수정 · 삭제

목록의 배포 수정 버튼으로 등록된 강의 정보를 변경한다. 키워드는 변경 불가 항목이다.

  • 슬라이드 URL을 비워두고 제출 → 제목만 변경되며 기존 슬라이드와 목차는 유지된다.
  • 새 슬라이드 URL을 입력하고 제출 → 해당 슬라이드로 전체 재배포되며 목차도 재생성된다.
  • 모달 좌측 하단의 배포 삭제 버튼 → 배포를 해제한다. 슬라이드 파일 자체는 삭제되지 않으나 공유 범위가 내부 접근으로 제한되고, 뷰어 링크는 차단되며, 목록에서 제거된다(키워드는 이후 재사용 가능).

구글 드라이브에 저장된 슬라이드를 웹상에서 직접 수정한 경우, 그 내용은 자동으로 반영되지 않는다. 배포 수정에서 같은 슬라이드 URL을 다시 입력해 제출해야 목차와 강의 컨텐츠(AI 기능이 참조하는 슬라이드 본문 포함)가 최신 내용으로 갱신된다.

5실시간 설문

목록의 실시간 설문 버튼으로 수업 중 사용할 익명 설문을 출제한다.

  1. 질문 내용과 문제유형(객관식·단답형·의견형)을 입력하고 학생들에게 공개를 선택한다.
  2. 화면에 표시되는 고유키를 학생에게 안내한다. 학생은 뷰어 화면의 답변하기 버튼으로 고유키를 입력한 뒤 답변을 제출한다 — 고유키가 다르면 동시간대 다른 강의실의 설문과 혼선되지 않는다.
  3. 응답 수집이 끝나면 설문종료를 선택한다. 더 이상 답변을 받지 않고 지금까지 모인 응답을 집계해 결과 화면을 띄운다(이 시점엔 아직 저장되지 않는다).
  4. 결과 화면에서 설문결과 저장 또는 결과를 저장하지 않고 종료 중 하나를 반드시 선택해야 창이 닫힌다. 저장을 선택해야만 서버에 영구 저장되어 나중에 다시 확인할 수 있고, 저장하지 않고 종료를 선택하면 결과는 그대로 사라진다(기록이 불필요한 분위기 환기용 질문은 저장하지 않고 종료해도 무방하다).

객관식·단답형은 정답률과 응답 분포를 막대그래프로 표시한다. 의견형은 정답 판정 없이 학생 의견을 취합해 요약을 표시하고, 그 아래에 제출된 답변 원문 전체를 항상 함께 나열한다.

AI 의견형 질문의 학생 답변들에 대한 요약은 AI전용 서버로 요청을 보내 처리한다. AI모드가 꺼져있거나 요약에 실패한 경우에는 요약 대신 "AI 서버 접근 불가로 답변 원문을 표시합니다" 안내와 함께 제출받은 답변 원문들을 그대로 출력한다. 제출된 답변이 하나도 없으면 "제출된 답변이 없습니다"라고 표시한다.

6시험문제 생성 AI

목록의 시험문제 생성 버튼으로 문제유형(객관식·단답형), 개수를 지정한 뒤 생성을 선택한다. 새 창에 문제와 정답이 표시되며, 별도로 저장되지 않으므로 보관이 필요하면 해당 창에서 복사하거나 인쇄한다.

등록된 강의 슬라이드의 본문 내용을 근거로 문제를 생성한다(ChatGPT 사용). AI 기능이 꺼져 있거나(AI_MODE) 서버 요청이 실패한 경우에는 오류 메시지가 출력된다.
